# Install

1. On your phone, open the [app release](https://github.com/jnyer27/noaa-osmand-charts/releases/tag/app) and download **noaa-route.apk**.
2. Open the downloaded file. Android asks to allow installs from your browser or file manager the first time; allow it.
3. Open **NOAA Route**. It needs Android 10 or newer.

To see routes and charts on a map, also install **OsmAnd+** (or OsmAnd) from the Play Store. See [Using routes in OsmAnd](osmand.html).

## Updates

New versions are published on the same [app release](https://github.com/jnyer27/noaa-osmand-charts/releases/tag/app) page. Download and open the new APK: it installs over the old one and keeps your settings, places and chart regions. The version number is shown in Android **Settings > Apps > NOAA Route**, and the [changelog](https://github.com/jnyer27/noaa-osmand-charts/blob/main/CHANGELOG.md) lists what changed.

The chart data is updated separately, every week. See [Chart regions and updates](regions.html).

## Permissions

| Permission | Used for |
|---|---|
| Location (optional) | The **Here** button and finding your chart region on first launch. Without it, type a position or pick on the map. |
| Notifications | Progress of chart map and vector chart downloads |
| Storage | None needed: routes and chart maps are saved to `Download/noaa-charts` |
